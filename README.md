# C++ Learning Repository

This repository contains my complete C++ learning journey, covering core language fundamentals, object-oriented programming (OOP), functional programming concepts, and basic data structures.

The goal of this project is to demonstrate practical understanding of C++ through hands-on implementations and structured examples.

---

## 📌 Topics Covered

### 🧱 Core C++ Fundamentals
- Variables, data types
- Control structures
- Functions
- Pointers and references

### 🧩 Object-Oriented Programming (OOP)
- Classes and objects
- Inheritance
- Polymorphism
- Virtual and pure virtual functions
- Abstract classes
- Static members
- Encapsulation

### 🔗 Data Structures
- Linked List implementation
- Basic memory management concepts

### ⚙️ Functional Programming Concepts
- Function-based design
- Modular logic structure
